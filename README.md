# Задачник

Мини-приложение для списка дел. Работает без сервера, данные хранятся в `localStorage` браузера.

## Запуск
Откройте `index.html` в браузере. Или локальный сервер:

    python3 -m http.server 8000   # затем http://localhost:8000

## Возможности
- добавление, отметка выполненными, удаление задач
- фильтры: все, активные и выполненные задачи
- счётчик оставшихся, очистка выполненных
- сохранение между перезагрузками, светлая и тёмная тема

## План развития
1. Приоритеты и дедлайны задач
2. Экспорт задач в JSON

## Ручные проверки
- Пустой ввод показывает ошибку и не добавляет задачу
- Задача сохраняется после F5
- Текст вида `<b>test</b>` отображается как текст
- Кнопка «Удалить выполненные» появляется только при наличии отмеченных
- Фильтры показывают только подходящие задачи
- Выбранный фильтр сохраняется после F5
