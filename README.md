# Задачник

Мини-приложение для списка дел. Работает без сервера, данные хранятся в `localStorage` браузера.

## Отчёт по практикуму

[Практикум 2: первая пользовательская функция и ветвление](docs/PRACTICE-2-REPORT.md)

[Практикум 4: поиск, рефакторинг и разрешение конфликта](docs/PRACTICE-4-REPORT.md)

Проверки без установки зависимостей: `node --test tests/app.test.cjs` (Node.js 20+).

## Запуск
Откройте `index.html` в браузере. Или локальный сервер:

    python3 -m http.server 8000   # затем http://localhost:8000

## Возможности
- добавление, отметка выполненными, удаление задач
- фильтры: все, активные и выполненные задачи
- поиск по названию без учёта регистра, совместимый с фильтрами
- счётчик оставшихся, очистка выполненных
- сохранение между перезагрузками, светлая и тёмная тема

## Оформление

Адаптивный интерфейс с лавандовой палитрой, карточками задач и отдельной
панелью поиска. Тема следует настройкам устройства. Предусмотрены состояния
клавиатурного фокуса, уменьшение анимации и системный режим высокой контрастности.
Шрифты и иллюстрация работают локально, без загрузки внешних ресурсов.

## План развития
1. Приоритеты и дедлайны задач
2. Экспорт задач в JSON

## Ручные проверки
- Пустой ввод показывает ошибку и не добавляет задачу
- Задача сохраняется после F5
- Текст вида `<b>test</b>` отображается как текст
- Кнопка «Удалить выполненные» появляется только при наличии отмеченных
- Фильтры показывают только подходящие задачи
- Выбранный фильтр сохраняется после F5
- Поиск «МОЛОКО» находит «Купить молоко»; очистка строки возвращает список
- Поиск работает вместе с фильтрами «Активные» и «Выполненные»
